# Mini Bash Programs

A collection of small Bash scripts built to practice shell scripting and automate common Linux administration tasks.

## Programs

- **log_check.sh** — Checks log files for errors and issues.
- **server_health_checks/** — Scripts for monitoring server health.

## Goals

- Practice Bash scripting concepts.
- Automate repetitive Linux tasks.
- Improve error handling and troubleshooting skills.
- Build practical DevOps automation experience.

## Usage

Make a script executable and run it:

```bash
chmod +x script.sh
./script.sh
```

More scripts and improvements will be added as I continue learning Bash scripting.
