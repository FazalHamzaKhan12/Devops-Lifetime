# Python Day 4

Day 4 of my Python learning journey — functions and a mini-project.

## Topics Covered

- User-defined functions: `def`, parameters, arguments, calling a function
- Built-in functions: `print()`, `len()`
- Module functions: `import math`, `import random`, `dir()`, `random.random()`, `random.randint()`
- Mini-project: number guessing game (uses `input()`, `while`, `if`/`elif`/`else`, `break`)

## Practice

The `practice/` folder contains four function exercises:

- `01_if-else_function_practice.py` — check if a number is odd or even
- `02_vowels-in-string_function_practice.py` — count the vowels in a string
- `03_prime-number_find_function.py` — check if a number is prime
- `04_average_marks_function.py` — calculate the average of a list of marks

## What I Learned

- Functions group reusable code with `def`, take parameters, and are called by name.
- Built-in functions like `print()` and `len()` are part of Python itself.
- Modules such as `math` and `random` add extra functions to Python.
- A function can return a value with `return`.
- Combining functions, loops, and conditions gives me a small program — the guessing game.

## DevOps Connection

Functions are how I will structure bigger automation scripts: one function for a health check, one for a deploy, one for a backup. Reusable functions keep scripts readable, testable, and maintainable — a key habit for DevOps tooling.
