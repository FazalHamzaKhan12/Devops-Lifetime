# Python Day 3

Day 3 of my Python learning journey — loops and collections.

## Topics Covered

- `for` loops and `while` loops
- `range()`, `break`, and `continue`
- Lists: indexing, slicing, and modifying (`append`, `insert`, `remove`, `pop`)
- Tuples: indexing, immutability, and unpacking
- Sets: unique values, `add`, `remove`, `discard`, union/intersection/difference
- Dictionaries: key–value pairs, adding/updating/removing, `keys()`, `values()`, `items()`

## Practice

The `practice/` folder contains two exercise files:

- `01_practice_loops.py` — loop exercises (odd numbers, a multiplication table, multiples, common multiples)
- `02_practice_lists_tuples_sets.py` — finding unique values with sets and searching a list of tuples

## What I Learned

- Lists are ordered and mutable; tuples are ordered and immutable.
- Sets store only unique values and remove duplicates automatically.
- Dictionaries store data as key–value pairs.
- `for` loops go over a sequence or collection; `while` loops run while a condition is true.
- `break` exits a loop, `continue` skips to the next iteration.

## DevOps Connection

- **Lists** → store multiple servers, IPs, or resources.
- **Tuples** → fixed groups of values (for example: name, IP, port).
- **Sets** → unique values without duplicates (for example: unique IPs from a log).
- **Dictionaries** → structured information about a server or service.
- **Loops** → process many resources, the core of automation and configuration scripts.
